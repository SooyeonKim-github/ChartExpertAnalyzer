# 영상 자막 규칙 매핑

프로젝트에서 사용한 신호는 영상에 등장한 다음 개념만 사용합니다.

- 전고점 돌파 + 전저점 미이탈 → 중기 상승추세
- 중기 상승추세 내부의 단기 하락 → '올라가고 있는데 싸지고 있음'
- 고점 2개 연결 → 추세 상단선
- 같은 추세선 아래로 복사, 과거 저점 통과 → 추세 하단선
- 하단 지지 → 상승 가능성 유지
- V자보다 쌍바닥/저점상승 확인
- 이평선 밀집 / 이평선 재돌파 / 이후 5일선 지지
- 바닥에서 터지는 거래량
- 거래량 동반 양봉을 지키거나 그 캔들 고가 돌파
- 추세 중심, 고점대, 추세 상단을 분할매도 가이드로 사용
- 추세선/저점 3~5% 이탈 시 손절 예시

사용하지 않는 요소: RSI, MACD, Stochastic, Bollinger Band, DMI/ADX, 120일선, 시장지수 필터, 수급, 재무, 뉴스, 테마, 머신러닝 특징량.
